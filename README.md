# leetcode-cs-fundamentals

A curated collection of LeetCode solutions focused on core data structures, algorithms, and interview preparation.

This repository is not intended to be a dump of every problem I have solved. Instead, it highlights selected problems that represent important CS fundamentals: arrays, hash maps, two pointers, sliding window, stacks, binary search, linked lists, trees, graphs, heaps, dynamic programming, and backtracking.
